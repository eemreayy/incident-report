# Frontend

Bu modül henüz oluşturulmadı. ReactJS ile geliştirilecek olan kullanıcı arayüzü buraya gelecek.

Hazır olduğunda:

- Kök dizindeki `docker-compose.yml` içinde yorum satırı olarak bekleyen `frontend` servisi açılır.
- Servis, backend'in `service_healthy` durumuna bağlanır; böylece API hazır olmadan başlamaz.

Backend API sözleşmesi için [`docs/PRD.md`](../docs/PRD.md) §8'e bakın.
